# Tela de Cadastro com PHP

## 📌 Sobre o projeto

Este projeto consiste no desenvolvimento de uma interface de cadastro de utilizadores, utilizando **HTML, CSS e PHP**, com o objetivo de explorar e aplicar conceitos fundamentais de desenvolvimento Frontend e Backend.

A aplicação apresenta uma interface moderna, intuitiva e responsiva, permitindo ao utilizador introduzir os seus dados pessoais através de um formulário de registo.

O projeto também tem como objetivo aprofundar conhecimentos sobre processamento de formulários, validação de dados e integração entre PHP e bases de dados.

## 🚀 Tecnologias utilizadas

- **HTML5** – Estruturação da interface.
- **CSS3** – Estilização e responsividade.
- **PHP** – Processamento e validação dos dados no servidor.
- **MySQL** – Gestão e armazenamento de dados (caso integrado).

## 🎯 Objetivos

- Praticar o desenvolvimento de interfaces de cadastro.
- Compreender a comunicação entre Frontend e Backend.
- Aplicar conceitos de processamento de formulários com PHP.
- Explorar a integração com bases de dados.
- Desenvolver boas práticas de organização de código.
